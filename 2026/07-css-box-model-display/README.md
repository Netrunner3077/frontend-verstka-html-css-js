## Блочная модель (box model)

Каждый элемент на странице — это **прямоугольная коробка**. Блочная модель
описывает, из чего складываются её размеры:

```text
┌─────────────────────────────────────────────┐
│ margin                                      │ ← внешний отступ
│ ┌───────────────────────────────────────┐ │
│ │ border                                │ │ ← граница
│ │ ┌─────────────────────────────────┐ │ │
│ │ │ padding                         │ │ │ ← внутренний отступ
│ │ │ ┌───────────────────────────┐ │ │ │
│ │ │ │                           │ │ │ │
│ │ │ │         content           │ │ │ │ ← содержимое
│ │ │ │                           │ │ │ │
│ │ │ └───────────────────────────┘ │ │ │
│ │ └─────────────────────────────────┘ │ │
│ └───────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**Слои от центра к краю:**

1. **content** — содержимое (текст, изображение);
2. **padding** — внутренний отступ (пространство между контентом и границей);
3. **border** — граница;
4. **margin** — внешний отступ (пространство между элементом и соседями).

**Занимаемая ширина:**
`width (content) + padding-left + padding-right + border-left + border-right + margin-left + margin-right`.

## `box-sizing` — алгоритм расчёта

По умолчанию `width` и `height` задают размер **только содержимого**
(content). Тогда padding и border **добавляются сверху**:

```css
.block {
    width: 500px;
    padding: 20px;
    border: 5px solid black;
    /* Реальная ширина: 500 + 40 + 10 = 550px */
}
```

Свойство `box-sizing` меняет алгоритм.

| Значение | Что включает width |
| --- | --- |
| `content-box` | Только содержимое (по умолчанию) |
| `border-box` | Содержимое + padding + border |
| `padding-box` | Содержимое + padding (устарело, не поддерживается) |

```css
.block {
    box-sizing: border-box;
    width: 500px;
    padding: 20px;
    border: 5px solid black;
    /* Реальная ширина: 500px (padding и border включены) */
}
```

**Почему `border-box` удобнее:**

Два блока по 50% ширины в ряд. При `content-box` с любым padding они
не влезут — суммарная ширина превысит 100%. При `border-box` — влезут.

**Современная практика:** применять `border-box` ко всем элементам сразу:

```css
*, *::before, *::after {
    box-sizing: border-box;
}
```

**Важно:** `box-sizing` не наследуется. Именно поэтому его применяют
через `*`, а не через `body`.

## `padding` — внутренний отступ

Пространство внутри элемента, между содержимым и границей.

```css
.block {
    padding: 20px;                     /* со всех сторон */
    padding: 10px 20px;                /* сверху/снизу — 10, слева/справа — 20 */
    padding: 10px 20px 30px;           /* сверху — 10, слева/справа — 20, снизу — 30 */
    padding: 10px 20px 30px 40px;      /* по часовой: top right bottom left */
}
```

**Правила:**

- Не наследуется.
- Не имеет отрицательных значений.
- Проценты считаются от ширины родителя (даже `padding-top` и `padding-bottom`!).
- Работает на всех элементах, включая строчные.

### Особенность на строчных элементах

На `<span>`, `<a>`, `<em>` горизонтальный padding расширяет элемент.
Вертикальный — визуально применяется, но не увеличивает высоту строки:
элемент «вылезает» и может накладываться на соседние строки.

## `margin` — внешний отступ

Пространство снаружи элемента, между ним и соседями.

```css
.block {
    margin: 20px;                      /* со всех сторон */
    margin: 10px 20px;                 /* сверху/снизу — 10, слева/справа — 20 */
    margin: 10px 20px 30px;            /* сверху — 10, слева/справа — 20, снизу — 30 */
    margin: 10px 20px 30px 40px;       /* top right bottom left */
}
```

**Правила:**

- Не наследуется.
- Может быть отрицательным — элемент сдвигается за границы родителя.
- Проценты считаются от ширины родителя.
- На строчных элементах вертикальные margin игнорируются.

### Центрирование через `margin: 0 auto`

Для блочного элемента с заданной width:

```css
.container {
    width: 900px;
    margin: 0 auto;   /* авто-отступы слева и справа = центрирование */
}
```

Работает только если у элемента задана `width` — иначе он и так займёт
всю ширину, и центрировать будет нечего.

## Схлопывание отступов (margin collapse)

Важное явление: вертикальные margin соседних блоков схлопываются —
берётся не сумма, а больший из них.

```html
<div class="a">Первый</div>
<div class="b">Второй</div>
```

```css
.a { margin-bottom: 30px; }
.b { margin-top: 20px; }
/* Расстояние между блоками: 30px (не 50px) */
```

**Когда схлопывание происходит:**

- между соседними блоками по вертикали;
- между родителем и первым/последним дочерним блоком (если нет padding,
border или overflow).

**Когда НЕ происходит:**

- между горизонтальными margin;
- если у родителя есть `padding`, `border` или `overflow: hidden`;
- если используется `display: flex` или `display: grid`;
- у строчных элементов.

**Как избежать:** использовать `padding` вместо `margin`, `overflow: hidden`
на родителе или `display: flex`.

## `width`, `height`, `min-*`, `max-*`

| Свойство | Что задаёт |
| --- | --- |
| `width` | Ширина |
| `height` | Высота |
| `min-width` / `min-height` | Минимальные значения |
| `max-width` / `max-height` | Максимальные значения |

```css
.block {
    width: 100%;        /* процент от ширины родителя */
    max-width: 1200px;  /* не шире 1200px */
    min-width: 320px;   /* не уже 320px */
    height: auto;       /* высота по контенту */
}
```

**Приоритеты:** `min-width > width > max-width`.
Если задано `width: 500px; max-width: 300px;` — реально элемент будет 300px.

**Проценты:**

- `width: 50%` — 50% от ширины родителя;
- `height: 50%` — 50% от высоты родителя, но работает только если у родителя
задана явная `height`. Иначе процент игнорируется.

**auto** — значение по умолчанию:

- для `width` — занять всю доступную ширину;
- для `height` — вычислить по содержимому.

## `overflow` — переполнение

Управляет тем, что происходит, когда содержимое не помещается в блок.

| Значение | Поведение |
| --- | --- |
| `visible` | Содержимое видно за границами (по умолчанию) |
| `hidden` | Содержимое за границами скрыто |
| `scroll` | Полосы прокрутки всегда |
| `auto` | Полосы прокрутки только при необходимости |
| `clip` | Как `hidden`, но без программной прокрутки (современное) |

```css
.block {
    height: 200px;
    overflow: auto;
}
```

Отдельно по осям:

```css
overflow-x: hidden;   /* скрыть горизонтальную прокрутку */
overflow-y: scroll;   /* всегда вертикальная прокрутка */
```

**Частое применение:** `overflow: hidden` на родителе + `border-radius`
= обрезка содержимого по скруглённым углам.

## `display` — отображение элемента

Определяет, как элемент ведёт себя в потоке документа.

| Значение | Поведение |
| --- | --- |
| `block` | Блочный: занимает всю ширину, начинается с новой строки |
| `inline` | Строчный: встраивается в текст, ширина по контенту |
| `inline-block` | Строчно-блочный: снаружи — строчный, внутри — блочный |
| `none` | Удалён из документа (место не занимает) |
| `flex` | Флекс-контейнер (изучается в уроке №17) |
| `grid` | Грид-контейнер (изучается в уроке №28) |

### `block`

```css
span { display: block; }
```

Строчный `<span>` становится блочным: занимает всю ширину, начинается
с новой строки. На него действуют `width`, `height`, `margin`, `padding`.

### `inline`

```css
div { display: inline; }
```

Блочный `<div>` становится строчным: ширина по контенту, свойства
`width`, `height`, вертикальные margin не работают.

### `inline-block`

Гибрид. Снаружи ведёт себя как строчный (обтекается текстом),
внутри — как блочный (работают `width`, `height`, `margin`, `padding`).

```css
.card {
    display: inline-block;
    width: 200px;
    height: 300px;
}
```

**Особенность:** между inline-block элементами в HTML появляется пробел
(как между словами). Это часто ломает сетки. Решения: `font-size: 0` на
родителе или `display: flex`.

### `none`

Удаляет элемент полностью:

- элемент не отображается;
- место не резервируется;
- в отличие от `visibility: hidden`, элемент недоступен через Tab
и не читается скринридером.

```css
.hidden {
    display: none;
}
```

## Итоги

- Блочная модель: content → padding → border → margin.
- `box-sizing` меняет алгоритм: `content-box` (по умолчанию) или
`border-box` (современная практика). Не наследуется.
- `padding` — внутренний отступ. Не может быть отрицательным.
- `margin` — внешний отступ. Может быть отрицательным.
- Схлопывание margin — вертикальные отступы соседей берут максимум.
- `width` / `height` — размеры. `max-width` приоритетнее `width`.
- `overflow` — управляет переполнением.
- `display` — `block`, `inline`, `inline-block`, `none` (+ `flex`, `grid`).
- `margin: 0 auto` центрирует блочный элемент с заданной `width`.
