## Что такое семантические элементы

**Семантика** — это смысл. Семантический элемент — это тег, который сообщает
браузеру, поисковым системам и скринридерам (программам чтения с экрана),
*что именно* находится внутри: вводная часть, навигация, основной контент
или нижний колонтитул.

До HTML5 для всего использовался `<div>`. Это работало, но браузер не понимал,
где шапка, где меню, а где подвал. С HTML5 появились теги, которые несут смысл:

| Тег | Смысл | Где используется |
| --- | --- | --- |
| `<header>` | Вводная часть | Шапка сайта, заголовок статьи |
| `<nav>` | Навигация | Меню, ссылки на разделы |
| `<main>` | Основной контент | Уникальное содержимое страницы |
| `<footer>` | Нижний колонтитул | Подвал: копирайт, контакты |
| `<section>` | Тематический раздел | Блок контента с заголовком |
| `<article>` | Самостоятельная единица | Пост, новость, карточка товара |
| `<aside>` | Боковая панель | Реклама, виджеты, ссылки |

**`<div>`** — универсальный контейнер **без семантики**. Сам по себе он ничего
не значит. Его используют, только когда ни один семантический элемент
не подходит [reference:6]. Например, для группировки нескольких элементов
с целью стилизации.

## Основные теги урока

### `<div>` — универсальный контейнер

Самый часто используемый тег. Не несёт смысла, используется для группировки
контента. Имеет **потоковое содержимое** (flow content): текст, изображения,
другие блочные и строчные элементы [reference:7].

```html
<div>
    Lorem ipsum dolor sit amet consectetur adipisicing elit.
</div>
```

### `<header>` — вводная часть

Используется для верхней части страницы («шапки») или заголовка раздела.
Обычно содержит логотип, название сайта, слоган, основное меню.

```html
<header>
    <h1>Название сайта</h1>
    <nav>...</nav>
</header>
```

### `<nav>` — навигация

Содержит основные навигационные ссылки: меню сайта, ссылки на разделы.

```html
<nav>
    <a href="#">Главная</a>
    <a href="#">О нас</a>
    <a href="#">Контакты</a>
</nav>
```

### `<footer>` — нижний колонтитул

Нижняя часть страницы («подвал»). Содержит копирайт, контактную информацию,
ссылки на политику конфиденциальности.

```html
<footer>
    © 2026 Мой первый проект
</footer>
```

## Блочные и строчные элементы

### Блочные элементы

Занимают всю ширину родителя и начинаются с новой строки.
Примеры: `<div>`, `<header>`, `<footer>`, `<nav>`, `<p>`, `<h1>–<h6>`,
`<ul>`, `<ol>`, `<li>`.

### Строчные элементы

Занимают только необходимую ширину и встраиваются в текст.
Примеры: `<span>`, `<a>`, `<strong>`, `<em>`, `<b>`, `<i>`, `<img>`.

```html
<p>Это <strong>важный</strong> текст в абзаце.</p>
```

## Атрибуты

У семантических элементов нет обязательных атрибутов. Чаще всего
используют глобальные атрибуты — те, которые можно вешать на любой элемент:

| Атрибут | Назначение |
| --- | --- |
| `class` | Имя класса для CSS и JS |
| `id` | Уникальный идентификатор |
| `lang` | Язык содержимого |
| `title` | Всплывающая подсказка |
| `style` | Встроенные стили |

Синтаксис `class`:

```html
<div class="wrapper">
    ...
</div>
```

После имени тега ставится пробел, затем `class=`, затем в кавычках — имя класса.
Это имя потом используется в CSS для стилизации.

## Пример: каркас страницы

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Каркас страницы</title>
</head>
<body>
    <header>
        <nav>
            Какое-то содержимое навигации сайта
        </nav>
    </header>

    <div>
        Lorem, ipsum dolor sit amet consectetur adipisicing elit.
    </div>
    <div>
        Lorem ipsum dolor sit amet consectetur adipisicing elit.
    </div>

    <footer>
        Какое-то содержимое подвала сайта
    </footer>
</body>
</html>
```

## Частые ошибки

| Ошибка | Последствие | Как исправить |
| --- | --- | --- |
| Использовать `<div>` там, где есть семантический тег | Плохо для доступности и SEO | Использовать `<header>`, `<nav>`, `<main>`, `<footer>` |
| Думать, что `header`/`footer`/`nav` можно только один раз | Ограничение неверно | Можно использовать несколько раз |
| Путать `class` и `id` | `id` должен быть уникальным | `class` — для групп, `id` — для одного элемента |
| Вкладывать блочные элементы в строчные | Невалидная разметка | Строчные — внутрь блочных, не наоборот |

## Практика

### Задание 1. Создай каркас страницы

Создай `index.html` со следующей структурой:

```text
<body>
    <header>
        <nav>...</nav>
    </header>
    <div>...</div>
    <div>...</div>
    <div>...</div>
    <footer>...</footer>
</body>
```

### Задание 2. Добавь семантику

Дополни каркас:

- внутрь `<header>` добавь `<h1>` с названием сайта;
- внутрь `<nav>` добавь три ссылки `<a href="#">`;
- внутрь `<footer>` добавь копирайт.

### Задание 3. Проверь себя

- Все ли теги закрыты?
- Нет ли пересечения тегов?
- Виден ли каркас в браузере (каждый блочный элемент с новой строки)?

### Задание 4 (дополнительное). Эксперимент

Добавь внутрь `<div>` строчный элемент `<span>` с текстом.
Посмотри, как он отображается: с новой строки или внутри текста?

## Итоги

- `header`, `footer`, `nav` — семантические элементы HTML5, они несут смысл.
- `div` — универсальный контейнер без семантики.
- Все эти элементы — блочные: занимают всю ширину и начинаются с новой строки.
- `class` — глобальный атрибут для связи с CSS.
- Семантические элементы можно использовать несколько раз на странице.
- `header`, `footer`, `nav` не заменяют друг друга — у каждого своя роль.
