## Текстовые теги

### Заголовки `<h1>`–`<h6>`

HTML предоставляет шесть уровней заголовков. `<h1>` — самый высокий уровень,
`<h6>` — самый низкий. Все заголовки — **блочные элементы**: они начинаются
с новой строки и занимают всю доступную ширину [reference:2].

```html
<h1>Заголовок 1 уровня</h1>
<h2>Заголовок 2 уровня</h2>
<h3>Заголовок 3 уровня</h3>
<h4>Заголовок 4 уровня</h4>
<h5>Заголовок 5 уровня</h5>
<h6>Заголовок 6 уровня</h6>
```

#### Правила использования

- Начинайте с `<h1>` и не пропускайте уровни (`<h1>` → `<h2>` → `<h3>`).
- Обычно на странице один `<h1>`, но в HTML5 допускается несколько,
если они находятся в разных `<section>` или `<article>`.
- Не используйте заголовки только для изменения размера текста — для этого есть CSS.

### Абзацы `<p>`

Тег `<p>` представляет абзац текста. Абзацы — блочные элементы,
они автоматически отделяются друг от друга отступами.

```html
<p>Первый абзац текста.</p>
<p>Второй абзац текста.</p>
```

### Строчный контейнер `<span>`

`<span>` — универсальный строчный контейнер. Он не начинает новую строку
и занимает только необходимую ширину. Используется для стилизации фрагментов
текста или группировки строчных элементов.

```html
<p>Обычный текст, <span style="color: red;">а это красный фрагмент</span>.</p>
```

`<span>` очень похож на `<div>`, но `<div>` — блочный, а `<span>` — строчный.

## Теги форматирования текста

### Семантические теги (несут смысл)

| Тег | Значение | Визуально |
| --- | --- | --- |
| `<strong>` | Важность, серьёзность | Жирный |
| `<em>` | Смысловое ударение | Курсив |
| `<ins>` | Вставленный текст | Подчёркнутый |
| `<del>` | Удалённый текст | Зачёркнутый |
| `<mark>` | Выделенный текст | Жёлтый фон |

```html
<p><strong>Важно:</strong> это <em>очень</em> важно.</p>
```

### Презентационные теги (только внешний вид)

| Тег | Значение | Визуально |
| --- | --- | --- |
| `<b>` | Жирный (без смысла) | Жирный |
| `<i>` | Курсив (без смысла) | Курсив |

```html
<p><b>Жирный текст</b>, <i>курсивный текст</i>.</p>
```

**Разница:** `<strong>` и `<em>` сообщают браузеру и скринридерам о смысле
фрагмента. `<b>` и `<i>` — только о внешнем виде. Если текст просто нужно
сделать жирным для красоты, используйте CSS (`font-weight: bold`).

## Ссылки `<a>`

Тег `<a>` (anchor — якорь) создаёт гиперссылку. Это строчный элемент.

### Атрибут `href`

`href` (hypertext reference) — обязательный атрибут, указывает, куда ведёт ссылка.

```html
<a href="https://developer.mozilla.org">MDN Web Docs</a>
```

### Атрибут `target`

`target` определяет, где откроется ссылка:

- `_self` — в текущей вкладке (по умолчанию);
- `_blank` — в новой вкладке.

```html
<a href="https://example.com" target="_blank">Открыть в новой вкладке</a>
```

**Безопасность:** при использовании `target="_blank"` рекомендуется
добавлять `rel="noopener"`. Это предотвращает доступ новой вкладки
к исходной странице через `window.opener`.

```html
<a href="https://example.com" target="_blank" rel="noopener">Ссылка</a>
```

### Абсолютные и относительные URL

- **Абсолютный:** `https://example.com/page.html` — полный адрес.
- **Относительный:** `./page.html`, `../img/photo.jpg` — путь относительно
текущего файла.

```html
<!-- Абсолютная ссылка -->
<a href="https://youtube.com">YouTube</a>

<!-- Относительная ссылка -->
<a href="./about.html">О нас</a>
```

## Изображения `<img>`

Тег `<img>` вставляет изображение. Это строчный элемент,
он не имеет закрывающего тега (пустой элемент).

### Атрибут `src`

`src` (source) — обязательный атрибут, содержит путь к изображению.

### Атрибут `alt`

`alt` (alternative text) — обязательный атрибут, содержит текстовое
описание изображения.

**Зачем нужен `alt`:**

- Если изображение не загрузилось — пользователь увидит текст.
- Скринридеры читают `alt` вслух для незрячих пользователей.
- Поисковые системы используют `alt` для индексации изображений.

Если изображение декоративное (не несёт смысла), `alt` должен быть пустым:

```html
<img src="decorative-line.png" alt="">
```

Если изображение несёт смысл, `alt` должен его описывать:

```html
<img src="chart.png" alt="График роста продаж за 2025 год">
```

```html
<img src="img/Dreamcore.jpeg" alt="Dreamcore">
```

## Списки

### Маркированный список `<ul>`

`<ul>` (unordered list) создаёт маркированный список.
Каждый элемент оборачивается в `<li>` (list item).

```html
<ul>
    <li>Первый элемент</li>
    <li>Второй элемент</li>
    <li>Третий элемент</li>
</ul>
```

### Нумерованный список `<ol>`

`<ol>` (ordered list) создаёт нумерованный список.

```html
<ol>
    <li>Первый шаг</li>
    <li>Второй шаг</li>
    <li>Третий шаг</li>
</ol>
```

### Вложенные списки

Внутри `<li>` можно разместить другой список:

```html
<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
    <li>Овощи</li>
</ul>
```

## Перенос строки `<br>`

Тег `<br>` создаёт перенос строки внутри текста. Это пустой элемент
(без закрывающего тега).

```html
<p>Первая строка.<br>Вторая строка.</p>
```

**Важно:** `<br>` следует использовать только для переносов, которые
являются частью контента (стихи, адреса). Для визуального разрыва между
блоками используйте CSS (`margin`, `padding`).

В HTML5 достаточно `<br>`, слэш (`<br />`) не нужен — он остался
от XHTML для совместимости.

## HTML-сущности (спецсимволы)

Некоторые символы нельзя записать напрямую, потому что они конфликтуют
с синтаксисом HTML. Для них используются сущности (entities):

| Сущность | Символ | Значение |
| --- | --- | --- |
| `&amp;` | `&` | Амперсанд |
| `&lt;` | `<` | Меньше |
| `&gt;` | `>` | Больше |
| `&copy;` | © | Копирайт |
| `&mdash;` | — | Длинное тире |
| `&nbsp;` | (неразрывный пробел) | Неразрывный пробел |

```html
<p>Windows &amp; Linux</p>
<p>&copy; 2026 Мой проект</p>
```

## Блочные и строчные элементы: сводная таблица

| Блочные | Строчные |
| --- | --- |
| `<h1>`–`<h6>` | `<span>` |
| `<p>` | `<a>` |
| `<ul>`, `<ol>`, `<li>` | `<img>` |
| `<div>` | `<strong>`, `<em>`, `<i>`, `<b>` |
| `<header>`, `<footer>`, `<nav>` | `<br>` |

**Правило вложенности:** блочные элементы могут содержать и блочные,
и строчные. Строчные — только строчные (исключение: `<a>` в HTML5 может
содержать блочные элементы).

## Частые ошибки

| Ошибка | Последствие | Как исправить |
| --- | --- | --- |
| Забыть `alt` у `<img>` | Невалидный HTML, плохо для доступности | Добавить `alt`, даже пустой |
| Вкладывать `<div>` в `<span>` | Невалидная разметка | Использовать `<span>` только для строчных |
| Использовать `<br>` для отступов | Плохая практика | Использовать CSS `margin` |
| Пропускать уровни заголовков | Плохо для SEO и доступности | `<h1>` → `<h2>` → `<h3>` |
| Не указывать `rel="noopener"` | Уязвимость безопасности | Добавить `rel="noopener"` |
| Путать `<b>` и `<strong>` | Семантическая ошибка | `<strong>` для важности, `<b>` для вида |

## Практика

### Задание 1. Свёрстай текст

Найди любой текст (статью, инструкцию) и свёрстай его, используя:

- абзацы `<p>`;

### Задание 2. Проверь вложенность

Проверь свою разметку:

- нет ли блочных элементов внутри строчных;
- все ли теги закрыты;
- нет ли пересечения тегов.

### Задание 3. Эксперимент с `alt`

Попробуй:

1. Убрать `alt` — валидатор покажет ошибку.
2. Поставить пустой `alt=""` — валидатор пропустит.
3. Поставить осмысленный `alt` — как это влияет на доступность?

### Задание 4 (дополнительное). HTML-сущности

Добавь в текст спецсимволы: `&copy;`, `&mdash;`, `&amp;`.
Проверь, как они отображаются в браузере.

## Итоги

- Заголовки `<h1>`–`<h6>` — блочные, образуют иерархию.
- `<p>` — блочный абзац.
- `<span>` — строчный контейнер.
- `<strong>`, `<em>` — семантические теги; `<b>`, `<i>` — презентационные.
- `<a>` — строчная ссылка, атрибуты `href` и `target`.
- `<img>` — строчное изображение, обязательные `src` и `alt`.
- `<ul>`, `<ol>`, `<li>` — списки.
- `<br>` — перенос строки, использовать только по назначению.
- HTML-сущности нужны для спецсимволов.
- Блочные элементы могут содержать строчные, но не наоборот.
