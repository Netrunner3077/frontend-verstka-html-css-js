## Свойства шрифта

### `font-family` — семейство шрифтов

Определяет, каким шрифтом будет отображаться текст.

```css
p {
    font-family: Arial, Helvetica, sans-serif;
}
Как работает: браузер идёт по списку слева направо и использует первый
доступный шрифт. Последним всегда указывают общий тип (generic family):

Тип	Описание	Примеры
serif	Шрифты с засечками	Times New Roman, Georgia
sans-serif	Рубленые (без засечек)	Arial, Helvetica, Verdana
monospace	Моноширинные	Courier New, Consolas
cursive	Курсивные	Comic Sans MS
fantasy	Декоративные	Impact
Правило: если в имени шрифта есть пробелы, оно заключается в кавычки:
"Times New Roman".

font-size — размер шрифта
css
p {
    font-size: 16px;    /* пиксели */
}
Единицы измерения:

Единица	Описание
px	Пиксели — абсолютная, не масштабируется
em	Относительно font-size родителя
rem	Относительно font-size корневого <html>
%	Проценты от родителя
vw / vh	От ширины / высоты вьюпорта
Современная практика: для адаптивной типографики используют rem
и clamp():

css
h1 {
    font-size: clamp(1.8rem, 2.5vw, 2.8rem);
}
font-style — начертание
css
p { font-style: italic; }
Значение	Описание
normal	Обычное начертание
italic	Курсив (специальный шрифт)
oblique	Наклон (наклон обычных знаков)
Разница: italic использует отдельный шрифт (имитирует рукописный),
oblique — просто наклоняет обычные символы. На практике чаще используют
italic.

font-weight — насыщенность
css
p { font-weight: 700; }   /* жирный */
p { font-weight: bold; }  /* то же самое */
Числовое	Ключевое	Описание
100	thin	Тонкий
300	light	Лёгкий
400	normal	Обычный
500	medium	Средний
600	semibold	Полужирный
700	bold	Жирный
900	black	Очень жирный
Важно: не все шрифты поддерживают все значения. Если шрифт не имеет
нужной насыщенности, браузер выберет ближайшую доступную или синтезирует её.

Вариативные шрифты (variable fonts) поддерживают любое значение
в диапазоне, например 450 или 550.

font — shorthand
Позволяет задать все параметры шрифта в одной строке:

css
p {
    font: italic bold 16px/1.5 Arial, sans-serif;
}
Порядок значений (обязателен):

font-style (опционально)

font-variant (опционально)

font-weight (опционально)

font-size / line-height (обязательно)

font-family (обязательно)

Важно: font-size и font-family обязательны. Без них правило
не сработает.

Свойства текста
color — цвет текста
css
p {
    color: #333333;          /* hex */
    color: rgb(51, 51, 51);  /* rgb */
    color: red;              /* имя */
}
Современные способы:

hsl(210, 50%, 20%) — тон, насыщенность, светлота;

rgba(0, 0, 0, 0.5) — с прозрачностью;

oklch(50% 0.1 200) — современное цветовое пространство (2023+).

text-align — горизонтальное выравнивание
css
p { text-align: center; }
Значение	Описание
left	По левому краю (по умолчанию для LTR)
right	По правому краю
center	По центру
justify	По ширине (браузер добавляет пробелы между словами)
start / end	Логическое выравнивание (учитывает направление текста)
Современная практика: использовать start / end вместо left / right
для поддержки языков с письмом справа налево (RTL).

text-decoration — оформление текста
Shorthand для трёх подсвойств:

text-decoration-line — тип линии;

text-decoration-color — цвет;

text-decoration-style — стиль.

css
p {
    text-decoration: underline;           /* подчёркивание */
    text-decoration: line-through;        /* зачёркивание */
    text-decoration: overline;            /* линия над текстом */
    text-decoration: underline wavy red;  /* подчёркивание, волнистое, красное */
    text-decoration: none;                /* убрать оформление */
}
Важно: none убирает подчёркивание у ссылок. Но если вы убираете
подчёркивание, нужно заменить его другим визуальным признаком (цвет,
жирность) — иначе ссылка не будет отличаться от текста.

Значение blink (мигание) устарело — не поддерживается современными
браузерами.

text-shadow — тень текста
css
p {
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}
Синтаксис: смещение_по_горизонтали смещение_по_вертикали [размытие] [цвет].

смещение_по_горизонтали — положительное вправо, отрицательное влево;

смещение_по_вертикали — положительное вниз, отрицательное вверх;

размытие (опционально) — чем больше, тем мягче тень;

цвет (опционально) — можно указывать до или после смещений.

Несколько теней — через запятую:

css
p {
    text-shadow: 1px 1px 2px #000, 0 0 10px red;
}
text-transform — преобразование регистра
css
p { text-transform: uppercase; }
Значение	Описание
none	Не менять регистр
capitalize	Первая буква каждого слова — заглавная
lowercase	Все буквы строчные
uppercase	Все буквы прописные
Важно: text-transform меняет только визуальное отображение —
в исходном HTML текст остаётся прежним. Для скринридеров и поисковых систем
это тоже визуальное преобразование.

Свойства интервалов
text-indent — отступ первой строки
css
p {
    text-indent: 40px;   /* красная строка */
    text-indent: 5%;     /* в процентах от ширины родителя */
}
Применяется к первой строке блока. Для «красной строки» в русском тексте
обычно используют 2em или 40px.

letter-spacing — межбуквенный интервал
css
p {
    letter-spacing: 2px;       /* разрядить */
    letter-spacing: -0.02em;   /* сжать */
}
Может быть отрицательным — используется в крупных заголовках для
уплотнения текста.

word-spacing — межсловный интервал
css
p {
    word-spacing: 5px;
}
Добавляет пробел между словами. Может быть отрицательным.

line-height — межстрочный интервал
css
p {
    line-height: 1.5;    /* множитель (рекомендуется) */
    line-height: 24px;   /* фиксированная высота */
}
Современная практика: использовать безразмерное число (множитель):

css
body {
    line-height: 1.5;
}
Почему безразмерное лучше: оно наследуется как множитель, а не как
вычисленная длина. Если у дочернего элемента другой font-size, интервал
пересчитается автоматически. С px — нет.

white-space — управление пробелами
css
p {
    white-space: nowrap;   /* запретить перенос */
    white-space: normal;   /* вернуть как было */
}
Значение	Описание
normal	Схлопывает пробелы, переносит по необходимости
nowrap	Схлопывает пробелы, не переносит
pre	Сохраняет пробелы и переносы (как <pre>)
pre-wrap	Сохраняет пробелы, но переносит
pre-line	Схлопывает пробелы, но сохраняет переносы
nowrap полезен для кнопок, ячеек таблиц — там, где текст не должен
ломаться.

Подключение Google Fonts
html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
rel="preconnect" — заранее устанавливает соединение с сервером шрифтов.
Это ускоряет загрузку на 100–300 мс.

display=swap — текст сначала отображается системным шрифтом, затем
подменяется загруженным. Это предотвращает «невидимый текст» (FOIT).

css
body {
    font-family: 'Inter', system-ui, -apple-system, sans-serif;
}

Итоги
font-family — семейство шрифтов, последним указывается generic family.

font-size — размер; современная практика: rem и clamp().

font-style — normal, italic, oblique.

font-weight — числовые (100–900) и ключевые (normal, bold).

font — shorthand; обязательны font-size и font-family.

color — цвет текста.

text-align — left, right, center, justify.

text-decoration — shorthand: линия + цвет + стиль.

text-shadow — тень; можно несколько через запятую.

text-transform — регистр: capitalize, lowercase, uppercase.

text-indent — отступ первой строки.

letter-spacing / word-spacing — интервалы; могут быть отрицательными.

line-height — безразмерное число предпочтительнее.

white-space: nowrap — запрет переноса.

Google Fonts подключаются через preconnect + display=swap.
