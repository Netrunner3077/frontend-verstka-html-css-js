## Организация файловой структуры проекта

### Зачем нужна структура?

Когда файлов становится много (HTML, CSS, JS, изображения, шрифты),
без чёткой структуры легко запутаться. Правильная организация экономит время
и позволяет сразу найти нужный файл.

### Базовая структура проекта
  
  ```text
  01-html-intro/
  ├── src/ # Рабочие файлы проекта
  │ ├── index.html # Главная (и пока единственная) страница
  │ ├── css/ # Таблицы стилей
  │ │ └── style.css
  │ ├── js/ # Скрипты
  │ │ └── script.js
  │ ├── img/ # Изображения и иконки
  │ └── fonts/ # Локальные шрифты
  ├── materials/ # Исходники: макеты, ТЗ, шрифты от заказчика
  └── README.md # Описание проекта
  ```

### Правила именования файлов и папок

| Правило | Пример | Почему |
|---|---|---|
| Только строчные буквы | `01-html-intro` | Веб-серверы регистрозависимы |
| Без пробелов | `01-html-intro` | Пробелы в URL заменяются на `%20` |
| Слова через дефис | `01-html-intro` | Google считает дефис разделителем слов[reference:10] |
| Не использовать кириллицу | `01-html-intro` | Проблемы с кодировкой на серверах |

> **Почему `index.html`?** Веб-сервер по умолчанию отдаёт файл `index.html`,
> когда пользователь заходит на корень сайта (`example.com/`). Это
> стандартное имя для главной страницы.[reference:11]

# Структура HTML-документа

### Что такое HTML?

**HTML** (HyperText Markup Language — язык гипертекстовой разметки) — это
язык разметки, который описывает структуру веб-страницы. Браузер читает
HTML-код и отображает содержимое в соответствии с ним.[reference:12]

### Элемент vs тег

Важно различать эти понятия:

- **Тег** — это конструкция в угловых скобках: `<h1>`, `</h1>`, `<meta>`.
- **Элемент** — это тег + содержимое + закрывающий тег:
  
  ```html
  <h1>Заголовок</h1>
  Здесь <h1> — открывающий тег, Заголовок — содержимое,
  </h1> — закрывающий тег.
  ```

## Пустые (void) элементы

Некоторые элементы не имеют содержимого и закрывающего тега: <meta>, <link>, <img>, <br>, <hr>, <input>.
Их называют пустыми элементами (void elements).

## Вложенность (nesting)

Элементы можно вкладывать друг в друга. Главное правило: закрывающий тег
внутреннего элемента должен идти раньше закрывающего тега внешнего.
  
  ```html
  <!-- Правильно -->
  <p><em>Текст</em></p>

  <!-- Неправильно: теги пересекаются -->
  <p><em>Текст</p></em>
  ```

## Регистр тегов

HTML не чувствителен к регистру: <H1>, <h1>, <H1> работают
одинаково. Но по конвенции все теги пишут строчными буквами.

## Базовая структура документа
  ```html
  <!DOCTYPE html>
  <html lang="ru">
  <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>Мой первый проект</title>
  </head>
  <body>
      <h1>Заголовок</h1>
  </body>
  </html>
  Разбор каждой строки
  <!DOCTYPE html>
  ```

**Что это:** объявление типа документа.
**Зачем:** переключает браузер в стандартный режим (standards mode).
Без него браузер уходит в quirks mode («режим чудачеств»), где имитируется
поведение старых браузеров, и современная вёрстка может ломаться.
Важно: должен быть первой строкой документа. Регистр не важен,
но по конвенции пишут заглавными.

<html lang="ru">

**Что это:** корневой элемент документа. Все остальные элементы — его потомки.
**lang="ru":** указывает язык содержимого. Влияет на:

1. произношение в скринридерах;
2. правила переноса слов;
3. SEO и автоматический перевод.

<head>
Что это: контейнер для метаданных — информации о странице,
которая не отображается напрямую в теле.
Что содержит: <meta>, <title>, <link>, <style>, <script>.

<meta charset="UTF-8">
Что это: указывает кодировку документа.
Зачем: без этого браузер может неправильно определить кодировку
и показать «кракозябры» вместо русского текста.
Важно: должен стоять как можно раньше — в первых 1024 байтах
документа.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Что это: управляет областью просмотра (viewport).
Зачем: без этого тега мобильные браузеры отображают страницу
в виртуальном окне шириной ~980px и затем масштабируют её.
width=device-width — ширина области просмотра равна ширине экрана.
initial-scale=1.0 — начальный масштаб 100%.
Это обязательный тег для адаптивной вёрстки.

<title>Мой первый проект</title>
Что это: заголовок страницы.
Где отображается: на вкладке браузера, в закладках, в результатах поиска.
Важно: только текст, теги внутри игнорируются.

<body>
Что это: тело документа — всё, что видно пользователю на странице.
Важно: в документе может быть только один <body>.

<h1>Заголовок</h1>
Что это: заголовок первого уровня — самый важный заголовок на странице.
Правило: на одной странице обычно один <h1>. Остальные заголовки —
<h2>...<h6> — образуют иерархию.

Примеры кода
Минимальный валидный HTML-документ
html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
</body>
</html>
Документ с несколькими заголовками
html
<body>
    <h1>Главный заголовок</h1>
    <h2>Подзаголовок</h2>
    <p>Абзац текста.</p>
</body>
Вложенные элементы
html
<p>Это <strong>важный</strong> текст.</p>

Частые ошибки начинающих
Ошибка	Последствие	Как исправить
Забыть <!DOCTYPE html>	Quirks mode, ломается вёрстка	Добавить первой строкой
Забыть meta charset	«Кракозябры» вместо русского текста	Добавить в <head>
Забыть meta viewport	Страница неадаптивна на мобильных	Добавить в <head>
Пересечение тегов (<p><em></p></em>)	Непредсказуемое поведение	Закрывать внутренний тег раньше внешнего
Несколько <h1> на странице	Плохо для SEO и доступности	Один <h1>, остальные — <h2>...<h6>
Пробелы и кириллица в именах файлов	Проблемы с URL и сервером	Только латиница, дефисы

Практика
Задание 1. Создай структуру проекта
Создай папку my-first-project/ со следующей структурой:

text
my-first-project/
├── src/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   ├── img/
│   └── fonts/
├── materials/
└── README.md
Задание 2. Напиши HTML-документ
Создай index.html с:

<!DOCTYPE html>;

<html lang="ru">;

<head> с charset, viewport и <title>;

<body> с одним <h1>.

Задание 3. Проверь себя
Открой index.html в браузере. Убедись, что:

текст из <h1> отображается на странице;

текст из <title> отображается на вкладке браузера;

русский текст отображается корректно (не «кракозябры»).

Задание 4 (дополнительное). Эксперимент
Попробуй:

Убрать <!DOCTYPE html> и обнови страницу — заметил изменения?

Убрать meta charset и обнови — что произошло с русским текстом?

Добавить второй <h1> — как это выглядит визуально?

Итоги
HTML-документ начинается с <!DOCTYPE html> — это переключает браузер
в стандартный режим.

<html lang="ru"> — корневой элемент с указанием языка.

<head> содержит метаданные: кодировку, viewport, заголовок.

<body> содержит видимое содержимое.

<h1> — главный заголовок страницы.

Файлы и папки именуются строчными буквами через дефис.

index.html — стандартное имя главной страницы.
