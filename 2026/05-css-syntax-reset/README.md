## Что такое CSS

**CSS** (Cascading Style Sheets — каскадные таблицы стилей) — язык описания
внешнего вида документа. Если HTML отвечает за **структуру** (что это),
то CSS — за **представление** (как это выглядит): цвет, шрифт, размер,
отступы, расположение.

CSS называется **каскадным**, потому что к одному элементу могут применяться
несколько правил из разных источников, и они «каскадом» накладываются друг
на друга по определённым правилам.

## Три способа подключения CSS

### 1. Внешний (external) — рекомендуемый

CSS выносится в отдельный файл и подключается через `<link>`:

```html
<link rel="stylesheet" href="css/style.css">
```

Атрибуты:

- `rel="stylesheet"` — тип связи: файл является таблицей стилей;
- `href` — путь к CSS-файлу.

Почему так лучше:

- Один CSS-файл можно подключить к сотням HTML-страниц.
- Браузер кэширует CSS — при повторных заходах страница загружается быстрее.
- Разделение структуры и представления: удобно поддерживать.

### 2. Внутренний (internal)

Стили пишутся прямо в `<head>` внутри тега `<style>`:

```html
<head>
    <style>
        p { color: red; }
    </style>
</head>
```

Используется редко — когда стили нужны только одной странице.

### 3. Встроенный (inline)

Стили пишутся прямо в атрибуте `style` элемента:

```html
<p style="color: red;">Текст</p>
```

Почему так не надо:

- Стили размазаны по разметке — тяжело поддерживать.
- Имеют наивысшую специфичность — перебить их сложно.
- Не кэшируются.

## Анатомия CSS-правила

```css
селектор {
    свойство: значение;
    свойство: значение;
}
```

Пример:

```css
p {
    color: red;
    font-size: 18px;
}
```

Разбор:

| Часть | Что это |
| --- | --- |
| `p` | Селектор — выбирает элементы, к которым применится правило |
| `{ ... }` | Блок объявлений |
| `color: red;` | Объявление — свойство + значение |
| `color` | Свойство |
| `red` | Значение |
| `;` | Разделитель объявлений. Обязателен между объявлениями, опционален после последнего |

## Селекторы

### По тегу

```css
p { color: red; }
```

Выбирает все `<p>` на странице. Специфичность: `0,0,0,1`.

### По классу

```css
.big-red { color: red; }
```

Выбирает все элементы с `class="big-red"`. Специфичность: `0,0,1,0`.

В HTML:

```html
<p class="big-red">Текст</p>
```

Имя класса — через дефис, строчными буквами (то же правило, что для файлов).

### По id

```css
#header { color: red; }
```

Выбирает один элемент с `id="header"`. Специфичность: `0,1,0,0`.

**Важно:** id должен быть уникальным на странице. Не используйте id для стилей — только для JS-навигации по якорям.

### Комбинированные

```css
span.big-red { ... }       /* тег + класс: <span class="big-red"> */
.block > p { ... }         /* дочерний: <p> прямо внутри .block */
.block p { ... }           /* потомок: <p> на любом уровне внутри .block */
.big-red span { ... }      /* span внутри .big-red */
a:hover { ... }            /* псевдокласс */
p::before { ... }          /* псевдоэлемент */
```

Разница между `.block > p` и `.block p`:

- `>` — только прямые дети;
- пробел — любой потомок (включая внуков и глубже).

## Каскад и порядок применения

Правила применяются сверху вниз. Если два правила имеют одинаковую
специфичность, побеждает то, что ниже в файле:

```css
p { color: red; }
p { color: blue; }   /* победит это правило */
```

Если специфичность разная — побеждает более специфичное, независимо
от порядка:

```css
p { color: red; }            /* 0,0,0,1 */
.big-red { color: blue; }    /* 0,0,1,0 — победит, потому что класс сильнее тега */
```

## Специфичность (specificity)

Специфичность — это «вес» селектора. Чем выше, тем приоритетнее правило.
Вычисляется как четыре числа (inline, id, class, tag):

| Селектор | Специфичность |
| --- | --- |
| `*` | 0,0,0,0 |
| `p` | 0,0,0,1 |
| `.class` | 0,0,1,0 |
| `p.class` | 0,0,1,1 |
| `#id` | 0,1,0,0 |
| `style=""` (inline) | 1,0,0,0 |

**`!important` перебивает всё.**

**Правило чтения:** сравниваем слева направо. `0,1,0,0` > `0,0,10,0`,
потому что id перебивает любое количество классов.

`!important` — крайняя мера. Использовать только когда нельзя
обойтись специфичностью (например, для переопределения стилей сторонних
библиотек). Злоупотребление приводит к «войне специфичностей».

## Наследование

Некоторые свойства наследуются от родителя к потомку, некоторые — нет.

**Наследуются:**

- `color`
- `font-family`, `font-size`, `font-weight`, `font-style`
- `line-height`
- `text-align`
- `visibility`

**НЕ наследуются:**

- `margin`, `padding`
- `border`, `background`
- `width`, `height`
- `display`, `position`

Пример:

```css
.parent {
    color: red;      /* наследуется */
    border: 1px;     /* НЕ наследуется */
}

.parent p {
    /* цвет — красный (унаследован), границы — нет */
}
```

Наследуемое значение можно переопределить:

```css
.parent { color: red; }
.parent p { color: blue; }  /* этот <p> будет синим */
```

## Обнуление стилей (reset)

### Зачем нужно

Каждый браузер применяет к HTML-элементам свои стили по умолчанию:

Chrome, Firefox, Safari по-разному отображают `<h1>` (размер),
`<ul>` (отступы), `<button>` (границы), `<input>` (внутренние отступы).

Это называется user agent stylesheet. Из-за разницы вёрстка «плывёт»:
на одном браузере отступы одни, на другом — другие.

Reset (обнуление) — это таблица стилей, которая сбрасывает
все стили браузера по умолчанию. После неё страница выглядит одинаково
во всех браузерах.

### Reset vs Normalize

| | Reset | Normalize |
| --- | --- | --- |
| Что делает | Сбрасывает всё в ноль | Приводит к единообразию, сохраняя полезные стили |
| Пример | `* { margin: 0; padding: 0; }` | Сохраняет `padding` у `<button>` |
| Автор | Eric Meyer (1999) | Nicolas Gallagher |
| Современность | Устарел | Более актуален |

**Современная практика:** гибридный подход — небольшая нормализация

- точечные сбросы. Популярный вариант — modern-css-reset Энди Белла:
<https://github.com/andy-piccalilli/modern-css-reset>

### Разбор reset.css

Текущий reset.css — классический «жёсткий» reset в стиле Эрика Мейера
с добавлениями. Работать он будет, но в нём есть несколько спорных
моментов:

| Строка | Проблема | Современное решение |
| --- | --- | --- |
| `:focus, :active { outline: none; }` | Ломает доступность — не видно фокуса при Tab | Использовать `:focus-visible` |
| `-moz-`, `-webkit-`, `-ms-` префиксы | Устарели | Убрать всё, кроме `-webkit-text-size-adjust` |
| `input::-ms-clear` | IE снят с поддержки в 2022 | Удалить |
| `button::-moz-focus-inner` | Неактуально с 2013 | Удалить |
| `html, body { height: 100%; }` | Ломает sticky-footer | `body { min-height: 100vh; }` |
| `line-height: 1` | Ухудшает читаемость | `body { line-height: 1.5; }` |
| `* { padding: 0; border: 0; }` | Ломает `<button>`, `<input>`, `<fieldset>` | Сбрасывать `margin`, а `padding` — точечно |

## Частые ошибки

| Ошибка | Последствие | Как исправить |
| --- | --- | --- |
| Забыть `;` между объявлениями | Следующее свойство не применится | Всегда ставить `;` |
| Забыть `}` в конце правила | Все последующие правила ломаются | Проверять закрытие |
| Использовать id для стилей | Специфичность 0,1,0,0 тяжело перебить | Использовать классы |
| `outline: none` без замены | Ломает навигацию с клавиатуры | `:focus-visible` |
| `!important` везде | «Война специфичностей» | Использовать только в крайнем случае |
| Имена классов через пробел | Не работает | Через дефис: `big-red` |

## Практика

### Задание 1. Подключи CSS

Создай `css/style.css` и подключи его в `index.html` через `<link>`.

### Задание 2. Поработай с селекторами

Дан HTML:

```html
<div class="block">
    <p>Текст 1</p>
    <p class="highlight">Текст 2</p>
</div>
```

Напиши CSS, чтобы:

- все `<p>` внутри `.block` были серыми;
- `.highlight` был красным;
- `.highlight` имел размер шрифта 20px.

### Задание 3. Проверь специфичность

Добавь два правила с одинаковой специфичностью, но разным порядком.
Проверь, какое победит. Поменяй специфичность одного — что изменилось?

### Задание 4. Обнуление

Создай `reset.css` и подключи его перед `style.css`.
Проверь: как изменилась страница? Какие стили пропали?

### Задание 5 (дополнительное). Сравни reset и normalize

Подключи вместо `reset.css` файл `normalize.css`
(<https://necolas.github.io/normalize.css/>). Сравни отображение страницы.

## Итоги

- CSS — язык описания внешнего вида. Название расшифровывается
как Cascading Style Sheets.
- Три способа подключения: внешний (рекомендуемый), внутренний, inline.
- Правило = селектор + блок объявлений. Объявление = свойство + значение.
- Селекторы: тег, `.class`, `#id`, комбинированные, псевдоклассы,
псевдоэлементы.
- Специфичность определяет, какое правило победит при конфликте.
- Каскад — правила ниже перезаписывают правила выше при равной
специфичности.
- Наследование: одни свойства (цвет, шрифт) наследуются, другие
(отступы, границы) — нет.
- Reset обнуляет стили браузера. Normalize — приводит их к единому
виду. Современная практика — гибридный подход.
- `outline: none` без замены — вредно для доступности. Используйте
`:focus-visible`.
- Вендорные префиксы (`-moz-`, `-ms-`) устарели. Оставить только
`-webkit-text-size-adjust`.
